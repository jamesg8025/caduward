# CaduWard

**AI-explained anomaly detection for EHR access logs. Built entirely on synthetic data.**


## The problem

Hospitals are required to audit who accesses patient records, but most access-log data goes unreviewed. Enterprise User Behavior Analytics (UBA) tools like Protenus or Imprivata FairWarning exist, but they're priced for large health systems, not small clinics — and even at the enterprise level, flagged events often surface as an unexplained risk score with no human-readable reasoning attached.

CaduWard is a lightweight, explainable alternative: it flags suspicious record access (off-hours logins, "break-glass" access with no linked encounter, staff-patient relationship snooping, VIP-chart spikes) and — instead of stopping at a score — uses Claude to generate a plain-English rationale a compliance officer can act on immediately.

## Why synthetic data

Real PHI never touches this project. The patient population and encounters are generated with [Synthea](https://github.com/synthetichealth/synthea) (MITRE's open-source synthetic patient generator, FHIR-native); the staff roster and access logs are generated by a custom script with deliberately seeded anomalies. Because the anomalies are planted, ground truth is known — which means the project can report real precision/recall numbers, something you can't honestly do against unlabeled real-world data anyway. See `docs/DATA_MODEL.md`.

## What it does

- Ingests synthetic FHIR patient/encounter data plus synthetic access logs
- Flags anomalous access via rule-based checks and embedding similarity (pgvector) against a per-role baseline
- Generates a structured, human-readable explanation for each flag via the Claude API
- Streams live alerts to a compliance dashboard
- Reports detector precision/recall against the injected ground truth

## Tech stack

| Layer | Choice |
|---|---|
| Frontend | Next.js (App Router) + Tailwind + shadcn/ui |
| API | Hono (or Next.js Route Handlers) |
| ORM / DB | Drizzle ORM + PostgreSQL + pgvector |
| Auth | better-auth |
| Realtime | Socket.IO |
| AI | Claude API (Sonnet), structured JSON output |
| Validation | Zod |
| Package manager | pnpm (workspaces) |
| Lint/format | Biome |
| Tests | Vitest |
| Local infra | Docker Compose |
| Synthetic data | Synthea (FHIR) + custom generator |
| Optional local-LLM story | Ollama |

## Getting started (target state — build toward this)

```
pnpm install
docker compose up -d                     # postgres+pgvector, redis
pnpm --filter synthetic-data generate    # seed synthetic patients/staff/access logs
pnpm --filter db migrate
pnpm dev                                 # runs web + worker
```
